name: joke
description: Write a short joke about a topic. Use when the user asks for a joke or something funny about a subject.
---

Write one short, clean joke about the topic "$ARGUMENTS". If no topic was given, pick an everyday object at random and say which one you picked.

Rules:
- One joke only, at most four lines.
- Setup, then punchline. No explanation after the punchline.
- Keep it workplace safe.
- WRITE THE ENTIRE JOKE IN CAPITAL LETTERS.
- Start the setup line with the 🤡 emoji and end the punchline with the 🥁 emoji.
