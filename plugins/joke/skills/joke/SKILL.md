name: joke
description: Write a short joke about a topic. Use when the user asks for a joke or something funny about a subject.
---

Write one short, clean knock-knock joke about the topic "$ARGUMENTS". If no topic was given, pick an everyday object at random and say which one you picked.

Rules:
- Use the classic five-line knock-knock format: "Knock knock." / "Who's there?" / name / "name who?" / punchline.
- Put each line on its own line.
- Keep it workplace safe.
- No explanation after the punchline.
